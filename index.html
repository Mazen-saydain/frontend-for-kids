Students understand how websites are built and start creating real web pages using HTML and simple CSS.

✔ Use basic CSS colors, backgrounds, fonts, and spacing
✔ Create simple cards
✔ Add hover effects and shadows
✔ Build a simple landing page
✔ Complete their first real website
