Level 2 Final Outcome

By the end of Level 2, each student will have built a complete static website using HTML and CSS. The website will include real sections, clean layouts, Flexbox organization, cards, forms, hover effects, and a simple responsive part, preparing students for Level 3 where they will add JavaScript interaction.
